# Catz-Embroidery — memory

**Durable findings that belong to no single file.** One fact per entry, and the entry says how it
was found rather than only what it concluded — a lesson without its measurement is an opinion that
has been repeated.

**This index is held to the directory by a gate** (`tests/memory.rs`). An entry written and not
indexed exists on disk and for nobody.

## What belongs here, and what does not

| The finding is... | It goes in |
|---|---|
| A ruling — we chose X over Y, and refused Z | `docs/decisions/INDEX.md`, appended |
| A convention for writing code | `docs/CODE.md` |
| A thing a test cannot see | `docs/TESTING.md` |
| Something the DST/PES/CSV formats do | `docs/FORMAT.md` |
| What crossed from a model repo | `docs/LESSONS.md` |
| What a word means | `docs/GLOSSARY.md` |
| What to do next | `docs/ROADMAP.md` — the queue, and the only one |
| Why one function is the way it is | a comment beside it, at length |
| Only true on one machine — what is installed, a GPU model, a shell quirk | `~/.claude/projects/*/memory/` |
| **None of the above, and it will bite again** | **here** |

That last row is the whole reason this directory exists.
