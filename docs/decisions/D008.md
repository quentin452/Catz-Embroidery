# D008 — The TSP stops at the first non-improving 2-opt pass

> Status: settled 2026-08-16.

## Decided

`PEmbroiderTSP.opt2` (the 2-opt crossing removal) stops at the first pass
that does not **shorten** the tour, instead of always running the caller's
`max_iter` passes (the Java's default 999).

**Measured** (the infinite canvas's save freeze): a design of four
interleaved 1600 mm circles hatched at 4 mm (1596 polylines, one colour
block) took ~265 s to save. The tour length is **invariant from the first
pass** (13134 — measured, every pass) and never converges: the crossings
between nearly-parallel hatch lines swap without changing the total length,
so `change` stays true and the Java runs all 999 passes × 5 trials × O(n²)
segment tests doing nothing. The stall rule leaves that design at ~0.34 s
(×800) — the last improving pass's arrangement, same total length as the
Java's 999-pass result.

**Converging designs are unaffected** — they stop where the Java stops
(`change == false` or a flat pass after the improvements); the M2 TSP
fixture tests (small scattered segments, trials=3) stay green.

## Refused

- **Keeping the 999-pass run** — the freeze: O(999 · n²) of provable waste
  when the length is invariant (measured).
- **Capping `max_iter` at the call sites** (e.g. 100) — linear relief only
  (measured: 50 → 14.6 s on the same design) and it punishes designs that
  genuinely need the passes.
- **Improving-only 2-opt swaps** (the standard variant: apply a crossing
  swap only when it shortens) — a different algorithm whose output diverges
  from the Java's on most designs, breaking the fixture comparisons far
  beyond the stall rule.

## What catches a violation

- The stall rule is the only early-exit in `opt2` besides `change == false`;
  a revert to the unconditional 999-pass loop is a regression of this
  ruling.
- The fixture tests are the guard that converging designs still match the
  Java: `tsp.rs` fixtures (trials=3) must stay green.
- A claim that the output of an oscillating design byte-matches the Java's
  — it deviates by this ruling (same stitches, same total length, a
  different order past the last improvement).

## History

- 2026-08-16: ruled after the infinite canvas's save freeze analysis —

  linear cost in `max_iter`, and the ×800 speedup of the stall rule with
  all fixtures green.
